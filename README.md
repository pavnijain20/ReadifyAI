# 🚀 Readify AI

Readify AI is an AI-powered application built using Python, Streamlit, and Azure Cognitive Services that can extract text from images, convert text into speech, and transform speech back into text.

---

## ✨ Features

- 🖼️ Image to Text using OCR
- 🔊 Text to Speech Conversion
- 🎤 Speech to Text Functionality
- 🤖 Azure AI Integration
- 💻 Interactive Streamlit Interface

---

## 🛠️ Technologies Used

- Python
- Streamlit
- Azure Cognitive Services
- OCR (Optical Character Recognition)
- Speech Recognition

## 🚀 How to Run the Project

### 1️⃣ Clone the repository

```bash
git clone <your-github-repository-link>
```

### 2️⃣ Install dependencies

```bash
pip install streamlit
pip install azure-cognitiveservices-vision-computervision
pip install azure-cognitiveservices-speech
pip install msrest
```

### 3️⃣ Run the application

```bash
python -m streamlit run app.py
```
